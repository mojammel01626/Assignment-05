# Project Name

 Dev Stack

## Description

Dev Stack is IT Solutions Web Site. Expoler the different fortend, backend, database, cyber security, IT support and development tools. Choose your technology build your empire. 

## Technologies Used

React
JavaScript
TypeScrpt
DaisyUI
React Toastify
React Icons
Tailwind


## 3 Key Features

1. Explore Technologies
   Users can browse different development technologies along with their category, difficulty level, rating, and description.

2. Build Your Technology Stack
   Users can select technologies and add them to their personal development stack.

3. Add & Remove Technologies
   Selected technologies are displayed in the right sidebar. Users can remove a technology, and its selection button becomes active again.
